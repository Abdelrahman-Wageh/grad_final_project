## 📝 Migration Guide

### For Developers: How to Use Riverpod Providers

**1. Import providers**:
```dart
import 'package:smartino/providers/providers.dart';
```

**2. Use ConsumerWidget instead of StatelessWidget**:
```dart
class MyWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // Access providers with ref
    final aiService = ref.watch(dualBrainAIProvider);
    return Container();
  }
}
```

**3. Use ConsumerStatefulWidget instead of StatefulWidget**:
```dart
class MyWidget extends ConsumerStatefulWidget {
  @override
  ConsumerState<MyWidget> createState() => _MyWidgetState();
}

class _MyWidgetState extends ConsumerState<MyWidget> {
  @override
  Widget build(BuildContext context) {
    // Access providers with ref
    final profile = ref.watch(currentProfileProvider);
    return Container();
  }
}
```

**4. Read vs Watch**:
- `ref.watch`: Rebuilds widget when provider changes
- `ref.read`: One-time read, no rebuild

**5. Access provider methods**:
```dart
// Read the notifier to call methods
ref.read(dualBrainAIProvider.notifier).setMode(AIMode.llm);
ref.read(mascotStateProvider.notifier).setHappy();
```
