# Abdelrahman Wageh — Resume (LaTeX)

ATS-friendly, single-page resume tailored for a **Remote Customer Service
Representative** role at **Community Phone** (US home-phone / landline provider).

## Files
- `Abdelrahman_Wageh_CV.tex` — LaTeX source
- `Abdelrahman_Wageh_CV.pdf` — compiled output

## Build
```bash
pdflatex Abdelrahman_Wageh_CV.tex
```
Only standard TeX Live packages are used (`geometry`, `enumitem`, `titlesec`,
`hyperref`, `lmodern`, `microtype`), so it also compiles on Overleaf.

## Why it is ATS-friendly
- Single-column layout (no text boxes, tables, or multi-column tricks that
  break parsers).
- Standard, machine-readable section headings: Professional Summary, Experience,
  Skills, Education, Languages.
- Plain selectable text — no icons or images for critical information.
- Reverse-chronological experience with clear `Title / Org / Dates / Location`.
- Keyword coverage relevant to the role: customer service, home phone, landline,
  troubleshooting, billing, de-escalation, CRM, first-contact resolution, remote.
